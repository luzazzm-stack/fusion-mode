# Harness one-shot / unattended run reference

Researched 2026-11-12 from official docs or official GitHub repos only. "not stated" = the pages read do not say. Nothing was installed or run except `--help` on the three already-installed CLIs (Claude Code, Codex, OpenCode).

| Harness | One-shot command | No-approval flag | Model flag | Output formats | Auth | Docs URL |
|---|---|---|---|---|---|---|
| Codex CLI | `codex exec "<task>"` | `--dangerously-bypass-approvals-and-sandbox` (also `-s/--sandbox <mode>`) | `-m, --model <MODEL>` | plain text; `--json` (JSONL events); `-o/--output-last-message <FILE>`; `--output-schema <FILE>` | ChatGPT login (`codex login`) or API key (`CODEX_API_KEY` for exec; `OPENAI_API_KEY`) | https://developers.openai.com/codex/noninteractive and https://developers.openai.com/codex/cli/reference |
| Claude Code | `claude -p "<task>"` | `--dangerously-skip-permissions` (or `--permission-mode <mode>`) | `--model <model>` | `--output-format text` (default), `json`, `stream-json`; `--input-format` | Claude subscription login or `ANTHROPIC_API_KEY` | https://code.claude.com/docs/en/cli-reference and https://code.claude.com/docs/en/headless |
| OpenCode | `opencode run "<task>"` | `--auto` (auto-approves permissions not explicitly denied) | `-m, --model provider/model` | `--format default` (formatted) or `json` (raw JSON events) | `opencode auth login` (log in to a provider; confirmed from local `opencode auth --help`), provider API keys | https://opencode.ai/docs/cli/ |
| Gemini CLI | `gemini -p "<task>"` | `--approval-mode=yolo` (`-y/--yolo` is deprecated); other modes: `default`, `auto_edit`, `plan` | `-m, --model` | `-o/--output-format text` (default), `json`, `stream-json` | Gemini API key (`GEMINI_API_KEY`) or Vertex/`GOOGLE_API_KEY`; Google OAuth login works but README says free personal and Google AI Pro/Ultra access moved to Antigravity CLI on 2026-06-18 (no free tier in Gemini CLI now) | https://github.com/google-gemini/gemini-cli/blob/main/docs/cli/cli-reference.md (flags) and https://github.com/google-gemini/gemini-cli (README) |
| Qwen Code | `qwen -p "<task>"` (or `--prompt`) | `--yolo` / `-y`; or `--approval-mode yolo` (modes: plan, default, auto-edit, auto, yolo) | `-m, --model` | `-o/--output-format text`, `json`, `stream-json` (+ `--include-partial-messages`); `--input-format text` or `stream-json` | `/auth` in app: Qwen Account with Plus/Pro subscription, or API key for a configured provider; free tier not stated | https://github.com/QwenLM/qwen-code/blob/main/docs/users/features/headless.md |
| Kimi Code CLI | `kimi -p "<task>"` (runs one prompt, no TUI) | none needed: `-p` already uses auto permission by default; `--yolo`/`--auto`/`--plan` cannot be combined with `-p` | `-m, --model <alias>` | `--output-format text` (default) or `stream-json` (only with `-p`) | `/login`: Kimi Code OAuth or Moonshot AI Open Platform API key | https://moonshotai.github.io/kimi-code/en/reference/kimi-command.html |
| Mistral Vibe | `vibe --prompt "<task>"` (also `-p`; prompt can be piped or `--prompt-file`) | `--auto-approve` or `--yolo` (without it, calls needing approval are denied in programmatic mode) | `--model ALIAS` (model alias from config) | `--output text` (default), `json` (all messages at end), `streaming` (NDJSON); `--output-dir` writes export.json | Mistral account sign-in or API key (env var name not stated in README or programmatic doc) | https://github.com/mistralai/mistral-vibe/blob/main/docs/programmatic-mode.md |
| Grok Build | `grok -p "<task>"` (`-p, --single`) | `--always-approve` | `-m, --model <MODEL>` | `--output-format plain`, `json` (one object at end), `streaming-json` (NDJSON) | `grok login` (cached token) or `XAI_API_KEY` | https://docs.x.ai/build/cli/headless-scripting.md |
| Poolside Agent CLI | `pool exec -p "<task>"` (or `-f file`, or stdin) | `--unsafe-auto-allow` (also `--sandbox required` or `disabled`) | not stated for `pool exec` (only the interactive `pool` command has `-m, --model`) | `-o markdown` (default) or `json` (NDJSON) | `POOLSIDE_API_KEY` for non-interactive; interactive sign-in via login docs | https://docs.poolside.ai/cli/cli-reference.md and https://docs.poolside.ai/cli/automated-mode.md |
| Antigravity CLI | `agy -p "<task>"` (aliases `--print`, `--prompt`) | `--dangerously-skip-permissions` (default headless mode is `request-review`; unapprovable actions are soft-denied, exit 0) | `--model <slug>` (list with `agy models`, e.g. `gemini-3.8-flash-medium`); also `--effort low/medium/high`, `--agent` | `--output-format text` (default), `json`, `stream-json` (NDJSON); `--json-schema` | Cached login from one interactive `agy` run first (headless fails with "authentication required" otherwise); free tier plus Google AI Plus/Pro/Ultra plans | https://antigravity.google/docs/cli/headless/ |
| Muse Code | `muse exec "<task>"` (or `--prompt-file`) | `--disable-approval` (keeps sandbox on) or `--yolo` (no approval and no sandbox) | `--model <id>` (default `muse-spark-1.2`) | plain stdout text; `--json` (JSONL events); exit codes 0/1/2/130/143 | `META_API_KEY` for CI, or browser sign-in; plans and subscriptions exist | https://dev.meta.ai/docs/muse-code/extending.md (Headless and CI section) |
| Aider | `aider --message "<task>"` (also `--msg`, `-m`, `--message-file`; process reply then exit) | `--yes-always` | `--model <MODEL>` (note: `-m` is message, not model) | plain text only; no JSON option on options page (`--dry-run`, `--no-pretty`, `--no-stream` exist) | Provider API keys: `--openai-api-key`, `--anthropic-api-key`, `--api-key PROVIDER=KEY`, or env vars such as `OPENAI_API_KEY` / `AIDER_*` | https://aider.chat/docs/config/options.html and https://aider.chat/docs/scripting.html |
| Pi | `pi --print "<task>"` (print mode is also used automatically when stdout is redirected) | NONE needed: Pi has no built-in permission system and runs with the launching user's permissions by default (`-a/--approve` only trusts project-local config) | `--model <pattern>` (accepts `provider/id` and `:thinking` suffix), `--provider <name>` | `--print` text; `--mode json` (JSON event stream, e.g. `> events.jsonl`); `--mode rpc` | `/login` inside Pi (subscription or API key); credentials per provider in providers doc | https://github.com/earendil-works/pi/blob/main/packages/coding-agent/docs/cli.md |
| Goose | `goose run -t "<task>"` (also `-i <file>` or `-i -` for stdin) | `GOOSE_MODE=auto` env var (modes: auto, approve, chat, smart_approve; docs list default as "auto") | `--provider <name> --model <name>` (or `GOOSE_PROVIDER` / `GOOSE_MODEL`) | `--output-format text` (default), `json`, `stream-json`; `-q/--quiet` prints only model reply | `goose configure`; 15+ providers by API key, or existing Claude/ChatGPT/Gemini subscriptions via ACP | https://github.com/aaif-goose/goose/blob/main/documentation/docs/guides/goose-cli-commands.md and https://github.com/aaif-goose/goose/blob/main/documentation/docs/guides/environment-variables.md |
| Cline CLI | `cline "<task>"` (one-shot and piped runs run once and exit) | `--yolo` (already the default for one-shot and piped runs; `--auto-approve false` turns approvals back on) | `-m <model>` with `-P <provider>` and `-k <key>` | `--json` (NDJSON events); plain text otherwise | `cline auth`: Cline account OAuth, ChatGPT subscription, or own API key (Anthropic, OpenAI, Gemini, OpenRouter, Bedrock, Vertex, Groq, etc.) | https://github.com/cline/cline/blob/main/apps/cli/README.md |
| Kilo CLI | `kilo run "<task>"` | `--auto` (auto-approves permission prompts unless a rule denies them; without it non-interactive runs auto-reject prompts) | `-m, --model provider/model` | `--format default` (formatted) or `json` (raw JSON events) | `kilo auth` manages providers and credentials (exact account/free-tier terms not stated on pages read) | https://kilo.ai/docs/code-with-ai/platforms/cli and https://github.com/Kilo-Org/kilocode (README, "Autonomous Mode") |
| Crush | `crush run "<task>"` (prompt as args or piped on stdin) | `-y` / `--yolo` (skip prompts, block dangerous commands); `-yy` also allows dangerous commands | `-m, --model <model or provider/model>` (also `--small-model`, `--reasoning-effort`) | plain text to stdout (redirectable); no JSON flag in the run command; `-q` hides spinner | Provider API key env vars (`ANTHROPIC_API_KEY`, `OPENAI_API_KEY`, `GEMINI_API_KEY`, `OPENROUTER_API_KEY`, etc.) or Charm Hyper sign-in | https://github.com/charmbracelet/crush/blob/main/internal/cmd/run.go (README does not document `crush run`; flags are in this source file) |
| ForgeCode | `forge -p "<task>"` (or `--prompt`) | not stated in README (README mentions a "restricted shell mode") | not stated as a CLI flag (only in-session `:model <id>` and `:config-model`) | not stated (README lists `:dump` for JSON conversation export) | `forge provider login` (interactive) or provider API key env vars such as `OPENROUTER_API_KEY` | https://github.com/tailcallhq/forgecode (README, "One-Shot CLI Mode" and "Command-Line Options") |
| Zero | `zero exec "<task>"` | `--auto low/medium/high` (autonomy ceiling) or `--skip-permissions-unsafe` (named in GitHub Action doc; not in README flag list) | `--model <id>` | text; `--output-format stream-json` with `--input-format stream-json`; README also says text/JSON/stream-JSON I/O | Provider API key env vars (`OPENAI_API_KEY`, `ANTHROPIC_API_KEY`, `GEMINI_API_KEY`, `MINIMAX_API_KEY` etc.) set via `zero setup`; OAuth subscriptions doc exists | https://github.com/Twigpine/zero (README "Headless exec") and https://github.com/Twigpine/zero/blob/main/docs/GITHUB_ACTION.md |
| Freebuff | NONE stated (README and freebuff.com/cli describe only interactive `freebuff`) | NONE stated | not stated (model picker in the app) | not stated | No account cost: free, ad-supported; README says no subscription, credits, or API key required (daily free hours, some models use hours) | https://github.com/CodebuffAI/freebuff and https://freebuff.com/cli |
